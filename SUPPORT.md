# Support

DeficitLens does not currently operate a hosted support channel. The code, verified report, CLI
help, FAQ, and reproducibility guide are the supported self-service surfaces for this local release
candidate. A public issue tracker and private security channel are external publication tasks.

Before requesting help, run:

```bash
deficitlens --help
deficitlens registry
deficitlens cases
python scripts/verify_release.py
```

Share only synthetic reproductions, the relevant package version, operating system, Python
version, command, and sanitized error text. Never share an Apple Health export or raw benchmark
data in an issue. Questions about diagnosis, calorie prescriptions, or treatment are outside
project scope.
